使い方と注意事項

      
    

    

      
      
使い方

      
    
        
  1. 「動画を選択」から動画を選ぶか、画面へ動画をドロップします。
    2. 
        
  2. スライダーまたは倍率入力で速度を決めます。左の動画ですぐに速度感を確認できます。
    3. 
        
  3. 「目標時間から決める」には入力できる1秒単位の範囲を表示します。開くだけでは速度は変わりません。時間を編集すると必要な倍率を逆算します。
    4. 
        
  4. ファイル名や画質を確認して変換し、結果をプレビューしてMP4を保存します。
    5. 
      

      
対応形式

      
プレビューはブラウザー標準の動画再生機能を使います。再生できない動画でも、動画情報を読み取れた場合は変換を試せます。

      
プライバシー

      
選択した動画はブラウザー内だけで扱います。このアプリからBrowser Kittyや外部サーバーへアップロードしません。

      
注意事項

      
    
        
  • プレビューで確認した速度でMP4へ変換できます。
    • 
        
  • 音程維持のプレビュー結果はブラウザーの対応状況によって差が出る場合があります。
    • 
        
  • 大きな動画では、端末性能やブラウザーのメモリ制限の影響を受ける場合があります。
    • 
        
  • 変換中はキャンセルできます。再変換をキャンセルした場合や失敗した場合、前の結果とその自動ファイル名は残ります。編集したファイル名も維持します。
    • 
        
  • 別の動画を選ぶと、前の変換結果とエラーは消去されます。
    • 
        
  • ブラウザーでプレビューできない動画でも、動画情報を読み取れた場合は変換を試せます。
    • 
        
  • 変換に必要な処理は配布HTMLに含まれており、動画を外部サーバーへ送信せずブラウザー内で実行します。
    • 
      

      
配布用HTMLは実行時通信を必要とせず、ローカルで直接開ける構成です。
